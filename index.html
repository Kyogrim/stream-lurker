Load Chrome Extensions

Stream Lurker containers are secure, isolated browser environments. To block ads (like Twitch pre-rolls/mid-rolls) or customize layouts, you can load unpacked Chrome extensions.

Quick Guide to Install uBlock Origin (Adblock):

  1. Download the unpacked uBlock Origin source zip from uBlock Origin Releases (e.g., uBlock0_x.x.x.chromium.zip).
  2. Extract the ZIP file into a permanent folder on your computer.
  3. Click the Add Unpacked Extension button below and select that extracted folder!

Connect Twitch

Twitch blocks sign-in from inside apps like this one, so we log in using your normal browser. This is a one-time step.

  1. and sign in (if you aren't already).
  2. On twitch.tv, press F12 and click the Console tab.
  3. Type copy(document.cookie) and press Enter. (If it warns about pasting, type allow pasting first, then re-run.)
  4. Paste below (Ctrl+V) and click Import.

Connect YouTube

Google blocks sign-in from inside apps like this one, so we import your session from your normal browser. Because Google's cookies are protected, this needs a free cookie-export extension (one-time).

  1. and make sure you're signed in.
  2. Install a cookie exporter such as Cookie-Editor or Get cookies.txt LOCALLY from your browser's extension store.
  3. On youtube.com, open the extension and Export (JSON or cookies.txt). It copies to your clipboard.
  4. Paste below (Ctrl+V) and click Import.
